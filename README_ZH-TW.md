# Kane Wang｜資料分析・商業分析

> 專注於製造、供應鏈與財務風險管理領域的資料分析與商業分析

擅長從營運問題與決策需求出發，釐清跨部門的資料定義、業務規則與管理權責，並運用 Python、SQL、Power BI 及 Microsoft Power Platform，將分析邏輯落地為可治理、可追溯且能持續運作的資料與決策平台。

具備從需求釐清、流程與資料設計、系統整合，到測試上線、後續維運及持續改善的完整專案落地經驗，不僅提供分析結果，也致力於將分析能力真正融入日常營運與決策流程。

代表專案包括：支援超過 **50 種原料、每月約新台幣 10 億元原料成本規模**的最低成本 BOM 與庫存決策平台，以及每月處理約 **1 億美元內部外匯交易量**、穩定運行超過四年的立帳前外匯風險管理系統。

## 核心能力

- **商業與流程分析：** 從營運需求出發，拆解現行流程、決策情境、業務規則及跨部門權責，將問題轉化為可執行的系統與分析需求。
- **資料整合、分析建模與治理：** 使用 Python、SQL 整合跨系統資料，完成資料清理、邏輯轉換、指標計算與分析模型實作，並建立一致的資料定義、來源、維護權責及版本管理機制，確保分析結果可靠、可追溯且可重現。
- **決策支援與流程自動化：** 結合 Power BI、Power Automate、Power Apps、Teams 與 Flask API，將分析結果轉化為日常營運流程、主動預警及決策資訊。
- **系統整合與營運落地：** 串接既有資訊系統、分析模型與下游平台，完成測試、上線、異常處理及後續維運。
- **領域經驗：** 製造營運、原料供應鏈、成本管理、資料品質與外匯風險管理。

## 精選專案

以下專案涵蓋製造、供應鏈、資料治理與財務風險管理，呈現如何從營運需求出發，完成流程分析、資料整合、規則設計、系統落地與決策支援。各專案的業務背景、系統架構及實作細節，可透過連結進一步查看。

### 1. [將分析模型落地為營運平台｜BOM Management Platform](https://github.com/ChienChienChien/BOM_Management_Platform/blob/main/README_ZH-TW.md)

將最低成本 BOM 模型所需的資料、規則與使用流程整合為可持續運作的決策平台，使模型成果能實際支援中期原料規劃與現場生產。

- **資料治理與跨部門協作：** 整合原料限制、成分、價格及生產計畫等跨部門資料，建立一致的資料定義、維護權責與確認流程。
- **模型營運化與系統整合：** 將分析模型串接至既有營運流程，同時支援中期原料規劃與 MES 現場即時計算，並保留輸入版本及執行結果以確保可追溯性。
- **決策支援與成果驗證：** 透過 Power BI 比較理論 BOM 與實際投料，建立模型結果的驗證及持續改善機制；平台支援超過 **50 種原料**及每月約 **新台幣 10 億元**的原料成本規模。

> 最低成本 BOM 核心模型、原料價格計算與成本管理由團隊其他成員負責；本案例聚焦於資料治理、流程設計、系統整合及模型落地。

### 2. [將供需資料轉化為前瞻性決策資訊｜原料庫存推估與告警系統](https://github.com/ChienChienChien/Material_Forecasting_System/blob/master/README_ZH-TW.md)

整合分散於不同系統的供需資料，建立未來庫存推估與風險預警機制，協助相關單位提前辨識缺料風險並採取行動。

- **供應鏈資料整合：** 串接庫存、採購、進貨、生產計畫與原料需求資料，將不同來源與時間粒度的資訊轉換為一致的逐日供需分析基礎。
- **業務指標與預警設計：** 依原料實際檢驗、放行及投料條件設計庫存指標與分級預警邏輯，呈現預計缺料日期、風險程度及形成原因。
- **流程自動化與決策支援：** 將原本每週約 **3 小時**的人工整理流程，轉為每日自動推估、Power BI 視覺化及 Teams 主動告警，支援超過 **50 種原料**的供需管理。

### 3. [建立可持續擴充的資料品質管理機制｜資料品質監控平台](https://github.com/ChienChienChien/Manufacturing_Data_Quality_Monitoring/blob/main/README_ZH-TW.md)

在資料進入報表、分析模型與營運決策前建立品質防線，將資料異常由使用者事後回報，轉為系統主動發現、通知與追蹤。

- **資料品質規則設計：** 依下游分析需求定義資料時效性、完整性及基本結構等檢核規則，使品質標準能被系統化執行。
- **監控流程自動化：** 使用 Python 與 Great Expectations 執行每日檢核，並整合 SQL Server、Power BI、Power Automate 與 Teams，形成從檢測到通知的完整流程。
- **分析治理與可追溯性：** 集中保存檢核摘要、規則明細及歷史結果，協助快速定位異常、追蹤品質變化，並可擴充至不同資料來源與分析流程。

### 4. [將複雜業務規則轉化為穩定交易流程｜立帳前外匯風險自動拋轉系統](https://github.com/ChienChienChien/FX_Hedging_Automation/blob/main/README_ZH-TW.md)

將外匯風險管理時點由應收、應付帳款立帳日向前延伸至外幣交易成立日，讓立帳前已形成的匯率風險也能被持續辨識與集中管理。

- **財務流程與交易生命週期分析：** 整合銷售、採購、立帳與匯率資料，將不同業務事件轉化為可追蹤的外匯部位與內部交易流程。
- **複雜規則系統化與跨系統整合：** 建立交易產生、異動、沖銷及到期處理機制，並將結果同步提供部位管理與風險管理流程，人工僅需處理例外情況。
- **營運規模與系統穩定性：** 每月處理約 **1 億美元的內部外匯交易量**，正式上線並穩定運行超過四年；系統負責內部風險拋轉，是否進行對外避險則由風險管理單位獨立決定。
